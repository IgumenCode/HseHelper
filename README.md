## Помощник первокурсника ИВТ МИЭМ НИУ ВШЭ

Прототип интеллектуального помощника для студентов первого курса образовательной программы «Информатика и вычислительная техника» МИЭМ НИУ ВШЭ. 

Приложение отвечает на вопросы по содержанию учебных дисциплин, формулам оценивания, спискам литературы и пререквизитам (на основе программ учебных дисциплин за 2026-2027 учебный год).

кстов ПУД для сохранения связности сложных элементов (формул оценивания и списков литературы).


## Установка и запуск


1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройте переменные окружения:**
   Создайте файл `.env` в корневой папке проекта и добавьте в него ваши учетные данные Yandex Cloud:
   ```env
   YANDEX_API_KEY=ваш_api_ключ_здесь
   YANDEX_FOLDER_ID=ваш_folder_id_здесь
   ```

3. **Запустите приложение:**
   ```bash
   streamlit run app.py
   ```
